# Unstoppable

Hay un vault tokenizado con un millón de tokens DVT depositados. Está ofreciendo flash loans gratis hasta que termine el período de gracia.

Para detectar cualquier bug antes de volverse 100% sin permisos, los desarrolladores decidieron ejecutar una beta en vivo en testnet. Hay un contrato de monitoreo para verificar la funcionalidad de los flash loans.

Comenzando con 10 tokens DVT en balance, demuestra que es posible detener el vault. Debe dejar de ofrecer flash loans.
